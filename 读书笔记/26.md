# 26.1 机器人

-   **定义**: 机器人是通过操纵真实世界去完成任务的实体智能体。
-   **效应器**: 机器人配备了效应器(effector)来对环境施加物理力量，改变自身、环境或周围人类的状态。
-   **传感器**: 机器人配备了各种各样的传感器来感知其所处的环境、周围人类以及自身的状态。
-   **目标**: 最大化地发挥预计的功效，即选择如何驱动其效应器施加正确的力，使状态向积累最多预期奖励的方向变化，并在物理世界中完成某些任务。
-   **环境**: 机器人在部分可观测且随机的环境中运作，且需要对人的行动进行预测。
-   **建模**: 通常将环境建模为连续状态空间和连续动作空间，一些机器人运行于高维空间。
-   **学习**: 机器人的学习是受约束的，因为真实世界的时间不可加速。因此，将从模拟环境中学到的东西转移到真正的机器人上是一个热门的研究领域。
-   **知识**: 实用的机器人系统需要体现关于机器人的先验知识、物理环境和要执行的任务，以便机器人可以快速学习、安全运行。
-   **机器人学的作用**: 机器人学综合了许多概念，包括概率状态估计、感知、规划、无监督学习、强化学习和博弈论，并提供了一个具有挑战性的应用范例，还引入了其他新概念。

# 26.2 机器人硬件

-   **智能体架构**: 成功的机器人对适用于任务的传感器和效应器设计的依赖并不少于智能体程序。

## 26.2.1 机器人的硬件层面分类

-   **拟人机器人**: 有一个脑袋和两条胳膊, 用腿或轮子移动，如图 26-1b。
-   **机械手**: 只是机器手臂, 不需要附加在机器人的身体上, 可以被螺栓固定在桌面或地板上, 如图 26-1a 所示。
-   **移动机器人**: 使用轮子、腿或螺旋桨在环境中移动, 包括四旋翼无人机、自主水下航行器、自主无人车和巡视器等, 如图 26-2 所示。
-   **腿式机器人**: 用于在轮子无法通行的恶劣地形行动。
-   **其他类型**: 假体机器人、外骨骼机器人、有翼机器人、蜂群机器人和智能环境。

## 26.2.2 感知世界

-   **传感器类型**:
    -   **被动传感器**: 如摄像头, 是环境的真实状态观察者。
    -   **主动传感器**: 如声呐, 向环境发送能量, 依赖能量反射回传感器。
-   **测距仪**: 用于测量与周围物体距离的传感器, 包括声呐、立体视觉、Kinect 和主动光学测距仪 (如飞行时间照相机、扫描激光雷达) 等, 如图 26-3 所示。
-   **雷达**: 通常是航空器最青睐的距离探测传感器, 可以探测以千米计的距离, 能穿透云雾。
-   **触觉传感器**: 基于物理接触测量距离, 仅用于测量距离机器人非常近的物体。
-   **位置传感器**: 使用距离测量技术作为确定距离的首要组成部分, 包括 GPS、差分 GPS、室内定位和水下定位等。
-   **本体感受传感器**: 将自身运动告知机器人, 包括轴编码器、计程和惯性传感器等。
-   **力传感器和扭矩传感器**: 用于测量机器人状态的其他重要方面, 对于处理确切尺寸未知的易碎物体尤其重要。

## 26.2.3 产生运动

-   **执行器**: 使效应器运动的机械装置, 包括变速箱、齿轮、电缆和链接, 包括电动执行器、液压执行器和气动执行器等。
-   **关节**: 执行器常用于移动关节, 包括旋转关节、平移关节、球形关节、柱状关节和平面关节等。
-   **夹具**: 机器人使用夹具与环境中的物体交互, 包括平行钳夹具、三指夹具和仿人手等。

# 26.3 机器人学解决哪些问题
-   **计算框架**: 确定性 environment 下的搜索、随机但完全可观测 environment 下的 MDP、部分可观测 environment 下的 POMDP 以及在智能体并非单独行动情形下的博弈。
-   **要素**: 奖励或效用函数、状态、动作、观测空间等。
-   **问题特点**: 非确定性的、部分可观测的以及多智能体的。
-   **形式化**:
    -   已知 environment 中单独行动时, 可形式化为 MDP。
    -   缺失了某些信息时, 可形式化为 POMDP。
    -   在人类附近行动时, 可用博弈来形式化。
-   **奖励**: 通常, 机器人的动作是为人类服务, 奖励是用户的奖励, 需要理解用户的需求, 或依赖工程师确定对用户需求的估计。
-   **动作、状态和观测空间**: 观测通常是原始的传感器反馈, 动作是发送到电动机的原始电流, 状态是机器人决策所需的知识。
-   **分层规划**:
    -   **任务规划**: 确定高层级动作, 如移动到门口、打开门、走到电梯、按下按钮等。
    -   **运动规划**: 负责找到使机器人从一个点到另一个点的路径, 完成每个子目标。
    -   **控制**: 用于使用机器人的执行器完成规划的运动。
-   **分别地**:
    -   **偏好学习**: 负责估计最终用户的目标。
    -   **人类预测**: 用于预测机器人 environment 中其他人类的动作。
-   **整合**: 各个层级分别取得的进展也带来对其进行重新整合的迫切需要。

# 26.4 机器人感知
-   **感知**: 机器人将传感器测得的数据映射到环境的内部表示的过程。
-   **感知之难**: 传感器有噪声, 而环境是部分可观测的、不可预测的, 且往往是动态的。
-   **良好內部表示的性质**:
    -   具有能使机器人进行良好决策的足够信息。
    -   结构化, 进而可以高效更新。
    -   自然而直观, 内部变量对应真实世界中的自然状态变量。
-   **算法**: 卡尔曼滤波器、HMM 以及动态贝叶斯网络可以表示转移以及部分可观测 environment 的传感器模型, 可以更新信念状态。
-   **记法**: 图 26-4 展示了本章所使用的记法: $X_t$ 是环境 (包括机器人在內) 在时刻 t 的状态, $z_t$ 是在时刻 t 接收到的观测值, 而 $A_{t-1}$ 是在接收到观测值后采取的动作。
-   **其它感知类型**：除了定位和感知建图，机器人也会感知温度、气味、声音等。这些数值中的大部分可以用某种动态贝叶斯网络来估计。
-   **机器学习的应用**：
    -   **无监督学习**：低维嵌入。
    -   **适应性感知技术**：根据环境的变化进行适应性的调整，例如图26-10中对于无人车形式路面的识别。
 -   **机器人感知可以看作动作和测量序列的时序推断**, 如图 26-4 所示。
 -   **从当前信念状态 $P(X_t | z_{1:t}, a_{1:t-1})$ 和新观测 $z_{t+1}$ 计算新的信念状态 $P(X_{t+1}|z_{1:t+1}, a_{1:t})$**:
    -  $P(X_{t+1}|z_{1:t+1}, a_{1:t}) = \alpha P(z_{t+1}|X_{t+1})\int_{}^{}P(X_{t+1}|x_t, a_t)P(x_t|z_{1:t}, a_{1:t-1})dx_t$ (公式 26-1)
    -  该式表明状态变量 $X$ 在时刻 $t+1$ 的后验概率是由前一时刻的对应估计递归算出的。
    -  需要先前的动作 $a_t$ 和当前的传感器测量 $z_{t+1}$。
    -  后验概率 $P(X_t|z_{1:t}, a_{1:t-1})$ 是所有刻画了我们从已有传感器测量和控制所得到的信息的状态的概率分布。
    -  概率 $P(X_{t+1}|x_t, a_t)$ 称为转移模型或运动模型, 而 $P(z_{t+1}|X_{t+1})$ 是传感器模型。
 -   **定位**: 找出东西在哪里的问题, 包括找到机器人本身。
    -   **简化假设**: 考虑在平坦的二维世界中的移动机器人, 且机器人已知该环境的精确地图 (图 26-7)。
    -   **位姿定义**: 移动机器人的位姿使用它的两个值为 $x$ 和 $y$ 的笛卡儿坐标及其值为 $θ$ 的朝向定义, 如图 26-5a 所示, 可表示为 $X_t = (x_t, y_t, θ_t)^T$。
    -   **运动学近似**: 每个动作包含两个“瞬时”速度——平移速度 $v_t$ 和旋转速度 $ω_t$。对于很小的时间间隔 $\Delta t$, 粗略的确定性运动模型为:
        
        $X_{t+1} = f(X_t, v_t, ω_t) = X_t + \begin{pmatrix} v_t\Delta tcosθ_t \\ v_t\Delta tsinθ_t \\ ω_t\Delta t \end{pmatrix}$
        
        真实的机器人运动模型通常使用均值为 $f(X_t, v_t, ω_t)$、协方差为 $Σ_v$ 的高斯分布建模。$P(X_{t+1}|X_t, v_t, ω_t) = N(f(X_t, v_t, ω_t), Σ_v)$。
    -   **传感器模型**:
        -   **地标模型**: 假设传感器探测的是环境中稳定的、可辨认的特征, 称为地标。机器人报告每个地标的距离和方位。
            
            在无噪声情况下, 可根据几何学计算得出。见图 26-5a。$z_t = h(x_t) = \begin{pmatrix} \sqrt{(x_l - x_t)^2 + (y_l - y_t)^2} \\ arctan\frac{y_l - y_t}{x_l - x_t} - θ_t \end{pmatrix}$
            
            噪声会使测量失真, 假设噪声服从协方差为 $Σ_z$ 的高斯分布, 则传感器模型为 $P(z_t|x_t) = N(h(x_t), Σ_z)$。
        -   **距离传感器阵列模型**: 使用有所不同的传感器模型, 每个传感器与机器人有固定的方位角, 产生一个距离值向量 $z_t = (z_1,…,z_M)$。
            
            给定位姿 $x_t$, 令 $z_j^*$ 为 $x_t$ 中沿着第 j 个波束方向算得的与障碍物的最近距离。通常, 假设不同波束的误差是独立同分布的, 因此有 $P(z|x) = \alpha\Pi_{j=1}^Me^{-(z_{t,j}-z_j^*)^2/2\sigma^2}$。图 26-5b 展示了一个例子。
    -   **比较距离扫描模型与地标模型**: 距离扫描模型好在不需要在呈现距离扫描结果前识别地标, 但如果有可见的、可识别的地标, 这些地标就能很快给出定位。
    -   **定位算法**:
        -   **卡尔曼滤波器**: 将信念状态用单个多元高斯分布表示。
        -   **粒子滤波器**: 用一系列对应状态的粒子表示信念状态。
        -   **蒙特卡罗定位 (MCL)**: 使用粒子滤波的定位, 算法是图 14-17 中的粒子滤波算法的实例, 只需提供合适的运动模型和传感器模型即可。图 26-6 展示了使用距离扫描传感器模型的 MCL 算法, 图 26-7 展示了算法的操作。
        -   **扩展卡尔曼滤波器 (EKF)**: 通过泰勒展开来线性化 $f$ 和 $h$ 的卡尔曼滤波器。图 26-8 展示了线性化一个(一维)机器人运动模型的概念, 图 26-9 展示了运行 EKF 定位算法的机器人的一系列估计。
    -   **同时定位与地图构建 (SLAM)**: 当环境地图不可取得时, 机器人必须获取地图, 且必须根据不太了解的地图导航, 同时还要在不知道自己的确切位置时构建地图。
